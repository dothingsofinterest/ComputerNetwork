








【OSI Model - Open Systems Interconnection Model - 开放式系统互联模型】
	【含义】：描述网络通信过程的参考模型(Reference Model)，没有具体实现
	【时间】：1984
	【注意】：为什么不直接使用 TCP/IP Model? OSI 只负责制定标准，规定网络通信应该如何分层、每一层应该承担什么职责，不负责具体实现。
	【模型】：Please Do Not Throw Sausage Pizza Away

		│	│
		│	├─5. Session		会话层

		│
		└─ Media Layers：负责传输相关的任务
			│

			│
			├─2. Data Link		链路层：network adapter cards / network interface
			│
			└─1. Physical		物理层：负责通过物理介质传输数据，涉及概念 cables、optical fibers、无线电波
