







【PDU - Protocol Data Unit - 协议数据单元】
	【含义】：数据在网络模型各层里的名称。数据在每层里都会被 Encapsulation 以添加新的控制信息，新形成的数据单位
	【模型】：
		│
		├─ Host Layers
		│	│
		│	├─7. Application	Data
		│	│
		│	├─6. Presentation	Data
		│	│
		│	├─5. Session		Data
		│	│
		│	├─4. Transport		Segment（数据段）
		│
		└─ Media Layers
			│
			├─3. Network		Packet（数据包）
			│
			├─2. Data Link		Frame（数据帧）
			│
			└─1. Physical		Bit（比特）
			
	【Encapsulation】：
		1. HTTP header, Data
		2. TCP header, HTTP header, Data
		3. IP header, TCP header, HTTP header, Data
		4. MAC header, IP header, TCP header, HTTP header, Data
		5. 01010101
